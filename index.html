Documentación del Entregables

Informe técnico de desarrollo e integración de IA

1. Arquitectura y Tecnologías

  • Frontend: HTML5 Semántico, CSS3 estilizado con Tailwind CSS CDN y Javascript Moderno (ES6+ Vanilla).
  • Procesamiento IA: API REST oficial de Google Gemini (`gemini-3-flash-preview`) con fallback a Motor de Simulación contextual offline.
  • Parsing Markdown: Biblioteca `marked.js` para renderizar tablas, negritas, listas e itinerarios de forma limpia.
  • Persistencia: `localStorage` para almacenamiento local del historial y claves API.

2. Uso de la IA durante el Desarrollo

Durante la fase de construcción de la aplicación, la Inteligencia Artificial fue empleada para:

Diseño de Prompts del Sistema: Establecimiento del System Prompt que condiciona la respuesta del bot como un guía turístico experto en gastronomía, transporte y presupuestos.
Optimización de Funcionalidades: Implementación de lógica para resúmenes de itinerarios y traducción instantánea utilizando prompts directos.
